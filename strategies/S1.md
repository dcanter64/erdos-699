# Strategy S1 — The Kummer small-part bound

**Route:** replace the EEES78 input $v > C(n,i)^{1/2}$ (equivalently $u < v$)
by a fully elementary bound on the small part $u$ coming from Kummer's
theorem: for every prime $p$, $p^{v_p(C(n,i))} \le n$, hence
$u \le n^{\pi(i-1)}$, with a sharpened form $u \le \prod_{p<i} q_p(n)$,
$q_p(n) = p^{\lfloor \log_p n\rfloor}$.
**Verdict, up front:** this route does **not** beat $3/2$, and the failure
is quantifiable exactly: along $j = ci$ the log-margin per unit $i$ tends to
$\Delta(c) - 1$, where $\Delta$ is an explicit entropy function with
$\Delta(3/2) = 0.9548 < 1$ and unique root $c^\ast = 1.3672$ on $[1,\infty)$.
So for every $c > c^\ast$ (in particular every $c > 3/2$) closure at ratio
$c$ fails for all large $i$, for both the crude and the sharpened bound.
The route also does not recover $j \le 3i/2$ for $i \ge 4$. What it *does*
deliver is real: (a) a second, **EEES-free and exception-free** finite
reduction, with an explicit bound $N_K(i,j)$; (b) unconditional all-$n$
closure for $i = 1$ (all $j$), $i = 2$ (all $j$), and $(i,j) = (3,5), (3,6)$,
and nothing else at the left endpoint, provably for $i = 3$ and
computationally for $4 \le i \le 60$; (c) combined with the existing
$n \le 10000$ sweep, **328,079 additional fully cleared pairs** in the open
region (exact integer count), raising the cleared total from 768,741 to
1,096,820, because far from the diagonal the Kummer interval is much
shorter than the EEES interval ($N_K \sim j^{e(i)}$ with $e(i) < 2$ against
$N \sim \kappa_i j^2$). Near the diagonal the comparison reverses: EEES
wins, and $\min(N_K, N)$ is the right combined bound.

Notation: $1 \le i < j \le n/2$, $C(a,b) = \binom ab$, $C(n,i) = u v$ with
$u$ supported on primes $< i$ and $v = V_i(n)$ on primes $\ge i$.
A counterexample is a triple with $\gcd(v, C(n,j)) = 1$.
$\pi(x)$ counts primes $\le x$; $\theta(x) = \sum_{p \le x} \log p$;
$h(p) = -p\log p - (1-p)\log(1-p)$ (natural log).

## 1. The idea in one paragraph

If $\gcd(v, C(n,j)) = 1$ then the key lemma (Phase 0) forces
$v \mid C(j, j-i)$, hence $v \le C(j, j-i)$ and therefore
$C(n,i) = uv \le u \cdot C(j, j-i)$. EEES78 controls $u$ indirectly through
$u < v$, i.e. $u < C(n,i)^{1/2}$, outside 12 small exceptions. Kummer's
theorem controls $u$ directly and elementarily: the exponent of $p$ in
$C(n,i)$ is the number of carries when $i$ and $n-i$ are added in base $p$,
and a one-line Legendre-formula argument gives $p^{v_p(C(n,i))} \le
p^{\lfloor\log_p n\rfloor} \le n$ for every prime $p$. Multiplying over
$p < i$ gives $u \le U^\sharp(n,i) := \prod_{p<i} q_p(n) \le
U(n,i) := n^{\pi(i-1)}$, with no exceptions and no external theorem beyond
Legendre/Kummer. A counterexample must therefore satisfy
$C(n,i) \le U^\sharp(n,i)\, C(j,j-i)$; since the crude ratio
$F_i(n) := C(n,i)/n^{\pi(i-1)}$ is strictly increasing in $n$ and tends to
infinity (Lemma 4, using only $\pi(i-1) < i$), this confines $n$ to an
explicit finite set per pair. The bound is strong when $i$ is small
relative to $n$ (it beats $C(n,i)^{1/2}$ at $n = 10^4$ for essentially all
$i \le 1289$) and weak near the diagonal $n \approx 2j \approx 2ci$, where
$\log U \approx i$ barely exceeds the entropy budget
$\log C(n,i) - \log C(j,j-i) \approx \Delta(c)\, i$ with $\Delta(c) < 1$:
that $4.5\%$ shortfall at $c = 3/2$ is the exact breaking point.

## 2. Key lemmas

**Lemma 1 (key lemma; Phase 0, restated).**
$C(n,i)\,C(n-i,j-i) = C(n,j)\,C(j,i)$. Hence any $d \mid C(n,i)$ with
$\gcd(d, C(n,j)) = 1$ satisfies $d \mid C(j,i) = C(j, j-i)$.
Consequently a counterexample satisfies
$$v \le C(j, j-i), \qquad C(n,i) \le u \cdot C(j, j-i).$$
*Proof:* Phase 0 Item 2, Steps 1–3 (double counting plus Euclid's lemma);
verified numerically in strong form on all 568,820 triples with
$n \le 240$. $\square$

**Lemma 2 (Kummer prime-power bound, sharp form).**
For every prime $p$ and $1 \le i \le n$,
$$p^{v_p(C(n,i))} \le q_p(n) := p^{\lfloor \log_p n \rfloor} \le n.$$
*Proof.* Legendre's formula gives
$v_p(C(n,i)) = \sum_{k \ge 1} \big( \lfloor n/p^k \rfloor -
\lfloor i/p^k \rfloor - \lfloor (n-i)/p^k \rfloor \big)$.
Each summand lies in $\{0,1\}$, since
$\lfloor x+y \rfloor - \lfloor x \rfloor - \lfloor y \rfloor \in \{0,1\}$
for $x = i/p^k$, $y = (n-i)/p^k$; each summand is $0$ for $p^k > n$.
Hence $v_p(C(n,i)) \le \#\{k : p^k \le n\} = \lfloor \log_p n \rfloor$.
(Kummer's theorem identifies $v_p$ with the number of base-$p$ carries
when adding $i$ and $n-i$; the summand at $k$ is the carry indicator out
of the $k$-th digit. The Legendre argument above is self-contained and
avoids quoting Kummer.) $\square$

**Lemma 3 (small-part bounds).** With $U^\sharp$ and $U$ as above,
$$u \;\le\; U^\sharp(n,i) \;=\; \prod_{p<i} q_p(n) \;\le\; n^{\pi(i-1)} \;=\; U(n,i),$$
and $U^\sharp(n,i)$ is nondecreasing in $n$. Also
$e^{\theta(i-1)} = \prod_{p<i} p \le U^\sharp(n,i)$ (as $q_p(n) \ge p$).
*Proof.* Multiply Lemma 2 over $p < i$; $u$ has no other prime factors.
$\square$

*How much the sharpening buys.* The deficit
$D(n,i) := \log U - \log U^\sharp = \sum_{p<i} \{\log_p n\}\,\log p$
(fractional parts) is substantial at practical sizes but $o(i)$ along the
diagonal: at $n = 2j$, $j = 1.6i$, $D = 20.1$ nats at $i = 50$ (26% of
$\log U$), $38.3$ nats at $i = 100$ (27%), $329.3$ nats at $i = 1000$
(24%). Asymptotically it buys nothing at the exponential scale:
$\theta(i-1) \le \log U^\sharp(2ci, i) \le \pi(i-1)\log(2ci)$ and both
bounds divided by $i$ tend to $1$ by the prime number theorem, so
$\log U^\sharp / i \to 1$, exactly as for $\log U / i$. The sharpening
shrinks intervals by a constant-to-subexponential factor (e.g. interval
top $2001 \to 1264$ for $(10,100)$), never the exponent and never the
diagonal sign.

**Lemma 4 (monotonicity and growth of the crude ratio).**
For every $i \ge 1$, $F_i(n) = C(n,i)/n^{\pi(i-1)}$ is strictly increasing
for $n \ge i$, and $F_i(n) \ge n^{\,i-\pi(i-1)}/i^{\,i} \to \infty$.
*Proof.* First $\pi(i-1) \le i/2$ for $i \ge 3$ (primes in $[2, i-1]$ are
$2$ together with odd integers, at most $1 + (i-2)/2 = i/2$ of them), and
$\pi(i-1) = 0$ for $i \le 2$; in particular $\pi(i-1) < i$ for all $i$.
Write $\pi = \pi(i-1)$. The ratio is
$\frac{F_i(n+1)}{F_i(n)} = \frac{n+1}{n+1-i}\big(\frac{n}{n+1}\big)^{\pi}$,
which exceeds $1$ iff $n^{\pi}/(n+1)^{\pi-1} > n+1-i$.
If $\pi = 0$ this is $n+1 > n+1-i$. If $\pi = 1$ (i.e. $i = 3$) it is
$n > n+1-i$, true as $i > 1$. If $\pi \ge 2$, Bernoulli's inequality
$(1 - \frac{1}{n+1})^{\pi-1} \ge 1 - \frac{\pi-1}{n+1}$ gives
$n^\pi/(n+1)^{\pi-1} = n\big(1-\frac1{n+1}\big)^{\pi-1}
\ge n - \frac{n(\pi-1)}{n+1} > n - (\pi-1) \ge n+1-i$,
using $\pi \le i$. Finally $C(n,i) = \prod_{t=0}^{i-1} \frac{n-t}{i-t} \ge
(n/i)^i$ (each factor $\ge n/i$ as $n \ge i$), so
$F_i(n) \ge n^{i-\pi}/i^i \to \infty$ since $i > \pi$. $\square$

**Lemma 5 (sawtooth structure of the sharp test).**
Let $G_i(n) = C(n,i)/U^\sharp(n,i)$ and
$\mathrm{Bad}^\sharp(i,j) = \{n \ge 2j : G_i(n) \le C(j, j-i)\}$.
Then (a) $G_i(n) \ge F_i(n)$, so $\mathrm{Bad}^\sharp(i,j)$ is finite and
contained in $[2j, N_K(i,j)]$, where
$N_K(i,j) := \max\{n : F_i(n) \le C(j,j-i)\}$ (an interval, by Lemma 4);
(b) $G_i$ is strictly increasing on every interval where $U^\sharp$ is
constant, and $U^\sharp(\cdot, i)$ jumps exactly at $n = p^e$ ($p < i$
prime, $e \ge 1$), by the factor $p$; hence every local minimum of $G_i$
on $[2j, \infty)$ is attained at $n = 2j$ or at a jump point $n = p^e$;
(c) $\mathrm{Bad}^\sharp$ need not be an interval: for $(i,j) = (3,7)$,
$\mathrm{Bad}^\sharp = \{16\}$, with $14, 15 \notin \mathrm{Bad}^\sharp$
(exact computation, §5).
*Proof.* (a) is $U^\sharp \le U$ plus Lemma 4. (b): $C(n,i)$ is strictly
increasing in $n \ge i$ while $U^\sharp$ is a nondecreasing step function
whose jumps are exactly the prime powers $p^e \le n$ crossing a threshold
$\lfloor \log_p n \rfloor$. (c) §5. $\square$

**Lemma 6 (entropy estimates).**
(i) $(n/i)^i \le C(n,i)$ and $C(j, j-i) \le 2^{j\, h((j-i)/j)/\log 2}$;
precisely, $\log C(n,i) = n\, h(i/n) + O(\log n)$ (Stirling).
(ii) For fixed $i$, $\log C(2j, i) - \log C(j, i) \to i \log 2$ as
$j \to \infty$.
(iii) Define, for $c \ge 1$,
$\Delta(c) := 2c\, h\!\big(\tfrac{1}{2c}\big) - c\, h\!\big(\tfrac1c\big)$.
Then $\Delta$ is strictly decreasing on $[1, \infty)$ (calculus on $h$;
verified on a fine grid), $\Delta(1) = 2\log 2 = 1.3863$,
$\Delta(3/2) = 0.9548$, $\Delta(2) = 0.8630$, $\Delta(c) \to \log 2$,
and $\Delta(c) = 1$ has the unique root $c^\ast = 1.3672$.
*Proof sketch.* (i) is standard (the lower bound is in Lemma 4; the
entropy form is Stirling's formula applied to the three factorials).
(ii): $C(2j,i)/C(j,i) = \prod_{t=0}^{i-1} \frac{2j-t}{j-t} \to 2^i$.
(iii): with $j = ci$, $n = 2j$, Stirling gives
$\log C(2j, i) - \log C(j, j-i) = \Delta(c)\, i + O(\log i)$, since
$C(j, j-i) = C(j, i)$ and $h$ is symmetric; monotonicity of $\Delta$ is a
routine derivative computation. $\square$

## 3. What this route delivers

**Theorem A (EEES-free finite reduction; no exceptions).**
If $(n, i, j)$ is a counterexample, then
$C(n,i) \le U^\sharp(n,i)\, C(j, j-i)$, i.e.
$n \in \mathrm{Bad}^\sharp(i,j) \subseteq [2j, N_K(i,j)]$.
Hence every pair $(i,j)$ requires only finitely many direct checks, with
no EEES78 input and no exception list. Combined with Phase 0, a
counterexample with $(n,i)$ not an EEES78 exception satisfies
$n \le \min(N_K(i,j), N(i,j))$, and $n \le N_K(i,j)$ unconditionally.
*Proof.* Lemma 1 gives $C(n,i) \le u\, C(j,j-i)$; Lemma 3 bounds $u$;
Lemma 5(a) gives the containment. $\square$

**Theorem B (unconditional all-$n$ closures in the open region).**
The following pairs with $j > 3i/2$ are closed for all $n$ by size alone:
(1) $i = 1$, every $j$; (2) $i = 2$, every $j$; (3) $(3, 5)$; (4) $(3, 6)$
(this one needs the sharpened bound). The pair $(3,7)$ is **not** closed
by size: $\mathrm{Bad}^\sharp(3,7) = \{16\}$ is nonempty, with equality
$u = U^\sharp = U = 16$ at $n = 16$; it is closed by the single direct
check $\gcd(v, C(16,7)) = \gcd(35, 11440) = 5 > 1$ (already inside the
$n \le 10000$ sweep).
*Proof.* (1) $u = 1$ (empty product), so a counterexample needs
$n = v \le C(j, 0) = 1$, impossible as $n \ge 2j \ge 4$.
(2) There is no prime $< 2$, so $u = 1$ and $v = C(n,2)$; a counterexample
needs $C(n,2) \le C(j, j-2) = C(j,2)$, but $n \ge 2j$ gives
$C(n,2) \ge C(2j,2) = j(2j-1) > j(j-1)/2 = C(j,2)$.
(3) $F_3(10) = C(10,3)/10 = 12 > 10 = C(5,2)$; by Lemmas 4–5,
$G_3(n) \ge F_3(n) \ge F_3(10)$ for all $n \ge 10 = 2j$.
(4) $C(6,3) = 20$. On $[12, 15]$, $U^\sharp = 8$ and $G_3$ is increasing
(Lemma 5(b)), with $G_3(12) = 220/8 = 27.5 > 20$; for $n \ge 16$,
$G_3(n) \ge F_3(n) \ge F_3(16) = 35 > 20$. So $\mathrm{Bad}^\sharp(3,6)
= \varnothing$. $\square$

**Proposition B′ (nothing else closes at the left endpoint).**
For $i = 3$ and $j \ge 8$, $R(3,j) := \log F_3(2j) - \log C(j, j-3) \to
-\infty$ (Lemma 6(ii) with $\pi(2) = 1$), and
$\mathrm{Bad}^\sharp(3,j) \ne \varnothing$ for every $7 \le j \le 2000$:
for $j \ge 8$ because $2j \in \mathrm{Bad}^\sharp$ (the scan below gives
$R^\sharp(3,j) < 0$), and for $j = 7$ by the exact singleton $\{16\}$. For $4 \le i \le 60$, an
exhaustive scan of the open region $3i/2 < j \le 2000$ found
$R^\sharp(i,j) := \log G_i(2j) - \log C(j, j-i) < 0$ for **every** pair:
no $i \ge 4$ pair is closed at $n = 2j$ even by the sharpened bound
(closest sampled approach $\approx -0.33$ nats at $(7, 11)$, far above
floating-point error; the prover team should re-run this in exact
arithmetic as verification task V1). Theorem C below shows this is
forced asymptotically, not an accident of range.

**Theorem C (the diagonal barrier; no $c > 3/2$, not even $3/2$, for
large $i$).** Fix $c \ge 1$ and let $j = \lfloor ci \rfloor$, $n = 2j$.
Then, as $i \to \infty$,
$$\frac{R(i, j)}{i} \to \Delta(c) - 1, \qquad
\frac{R^\sharp(i, j)}{i} \to \Delta(c) - 1,$$
for both the crude and sharpened margins. In particular, for every
$c > c^\ast = 1.3672$ there exists $i_0(c)$ such that no pair
$(i, \lfloor ci \rfloor)$ with $i \ge i_0(c)$ is closed by this route;
since $c^\ast < 3/2$, the route cannot prove $j \le ci$ for any
$c > 3/2$ uniformly in $i$, and cannot even re-derive the known
$j \le 3i/2$ closure for large $i$ (the asymptotic margin at $c = 3/2$
is $\Delta(3/2) - 1 = -0.0452$ per unit $i$).
*Proof sketch.* By Lemma 6(i),(iii),
$\log C(2j, i) - \log C(j, j-i) = \Delta(c)\, i + O(\log i)$. For the
crude margin subtract $\pi(i-1)\log(2j)$; by the PNT,
$\pi(i-1)\log(2j)/i \to 1$. For the sharp margin, Lemma 3 gives
$\theta(i-1) \le \log U^\sharp \le \pi(i-1)\log(2j)$, and
$\theta(i-1)/i \to 1$ (PNT), so $\log U^\sharp/i \to 1$ as well. $\square$

*Fixed-$i$ comparison (where Kummer wins).* For fixed $i$ and
$j \to \infty$, the Kummer condition $C(n,i) \le n^{\pi} C(j, j-i)$ with
$C(m, i) \sim m^i/i!$ gives
$$N_K(i,j) = j^{\,e(i)}\,(1 + o(1)), \qquad
e(i) = \frac{i}{i - \pi(i-1)},$$
against $N(i,j) \sim \kappa_i j^2$ for EEES. Now $e(i) < 2$ iff
$\pi(i-1) < i/2$, which holds for all $i \ge 3$ except the ties
$i \in \{4, 6, 8\}$ ($\pi(i-1) = i/2$, $e = 2$; there constants decide,
and numerically EEES wins: tops $17$ vs $20$ at $(4,7)$, $66$ vs $90$ at
$(4,12)$, sharp tops). Values: $e(3) = 1.5$, $e(5) = 1.667$,
$e(7) = 1.75$, $e(10) = 1.667$, $e(100) = 1.333$, $e(1000) = 1.202$,
$e(i) \to 1$. So for fixed $i \notin \{4,6,8\}$ and all large $j$, the
Kummer interval is eventually strictly shorter; near the diagonal
($j \approx 1.6i$, $i$ large) it is longer (Theorem C regime). The two
reductions are complementary, and $\min(N_K, N)$ is the operative bound.

**Theorem D (payoff at the sweep scale: 328,079 new fully cleared
pairs).** Let $2j \le 10000$ and $j > 3i/2$. If
$$C(j, j-i) \;<\; \frac{C(10001, i)}{10001^{\pi(i-1)}} \;=\; F_i(10001),$$
then $N_K(i,j) \le 10000$ (exactly, by Lemma 4 monotonicity in both
directions), so by Theorem A no counterexample has $n > 10000$, and the
completed sweep excludes $n \le 10000$: the pair is fully cleared, with
no use of EEES78. Exactly **328,079** open-region pairs with
$i \le 1000$, $2j \le 10000$ satisfy this criterion while failing the
EEES criterion $N(i,j) \le 10000$ (exact integer recount, §5), i.e. they
are newly cleared; $318,242$ of them have $i \ge 3$ (the rest are
$i \in \{1, 2\}$, already closed for all $j$ by Theorem B). The fully
cleared total rises from $768{,}741$ to $1{,}096{,}820$ of the
$4{,}249{,}500$ classified pairs. Sample thresholds $J_K(i)$ (largest
$j$ cleared by the criterion) against the EEES values $J_E(i)$ from
RESULTS.md: $(i, J_E, J_K) = (3, 112, 465)$, $(5, 142, 253)$,
$(10, 199, 255)$, $(11, 209, 355)$, $(50, 454, 654)$, $(100, 656, 1045)$,
$(500, 1597, 1950)$, $(1000, 2391, 2541)$. The criterion is sufficient,
not necessary: the sharp sawtooth test (Lemma 5) can only add pairs.
For $i \le 30$ the exceptional indices with $J_K(i) \le J_E(i)$ are
exactly $\{4, 6, 8, 9, 14, 20\}$, driven by jumps of $\pi(i-1)$ when
$i - 1$ is prime (each jump divides the threshold by $10001$).

## 4. The breaking point, honestly assessed

**(a) The exact diagonal shortfall.** Closing $(i, ci)$ at $n = 2j$
needs, on the log scale,
$\log C(2j,i) - \log C(j, j-i) > \log U$. The left side is
$\Delta(c)\, i + O(\log i)$ with $\Delta(3/2) = 0.9548$; the right side
is $i + o(i)$ for *both* bounds (Theorem C). The route misses by
$(1 - \Delta(c))\, i$ nats: $0.045\, i$ at $c = 3/2$, $0.071\, i$ at
$c = 1.6$, $0.137\, i$ at $c = 2$. EEES78 succeeds at $3/2$ because it
compares $v$ against $C(j,j-i)$ *squared* through
$C(2j, 2(j-i)) \le C(2j, i)$; the Kummer comparison has no such squaring,
and no sharpening of $u$ that keeps $\log U/i \to 1$ can repair this.

**(b) Convergence is slow, so finite margins are worse than the
limit.** At $c = 1.6$, $R/i$ (crude) is $-0.516$ at $i = 100$, $-0.427$
at $i = 1000$, $-0.399$ at $i = 2000$, against the limit $-0.071$:
$\pi(i)\log(2j)/i$ approaches $1$ only like $1 + O(\log\log i/\log i)$.
The sharpened margin $R^\sharp/i$ is $-0.133$, $-0.098$, $-0.091$ at the
same points: much closer to the limit, still negative. At every computed
size, near the diagonal the Kummer interval exceeds the EEES interval
(e.g. $(50, 80)$: sharp top $197$ vs $N = 178$; $(100, 160)$: $373$ vs
$356$), while far from the diagonal it is far below it
($(10, 100)$: $1264$ vs $2385$; $(3, 20)$: $76$ vs $285$). The crossover
is the content of Theorems C and D.

**(c) Crossover against the EEES strength $C(n,i)^{1/2}$.** The Kummer
bound on $u$ is stronger than EEES78's $u < C(n,i)^{1/2}$ iff
$2\pi(i-1)\log n < \log C(n,i)$. At $n = 10^4$ this holds for all
$i \le 1289$ **except** $i \in \{4, 6, 8, 9, 12, 14, 15, 20, 1284,
1285\}$ (the small exceptions are exactly the $\pi$-jump indices, where
$\pi(i-1)$ jumps while $C(n,i)$ barely grows), and for no
$1290 \le i < 5000$. So at the sweep scale the elementary bound is the
stronger of the two for essentially the whole classified range
$i \le 1000$; its failure near the diagonal is not weakness of the
$u$-bound relative to EEES, it is the missing Vandermonde squaring in
(a). Conversely, for $i$ large relative to $\log n$ the bound degrades
gracefully but decisively: the sufficient condition
$i \log(n/i) > 2\pi(i-1)\log n$ (from $C(n,i) \ge (n/i)^i$) fails once
$\pi(i-1)\log n$ overtakes $\tfrac12 i\log(n/i)$, and past $i^\ast(n)$
the Kummer interval is the longer one at every $j$.

**(d) Slack against the truth.** The bound is typically nowhere near
tight, because Lemma 2 lets *every* small prime simultaneously attain
its maximal carry count, which never happens. Log-scale values
($\log u$ true, via Legendre exponents):

that closes the diagonal must exploit correlations between the carries

this is the structural reason EEES78's multiplicative argument is doing
real work that Kummer cannot imitate.

**(e) What would have to be true.** A size-only variant of this route
closes $j \le ci$ for large $i$ iff it supplies $\log U \le
(\Delta(c) - \varepsilon) i$, i.e. $u \le C(n, i)^{\Delta(c)/(2c\,h(1/2c))}$-
strength at $n = 2ci$: at $c = 3/2$ that is $u \le C(n,i)^{0.4997}$,
essentially the EEES threshold $u < C(n,i)^{1/2}$ itself. So the Kummer
route, pushed to its limit, *re-derives the need for EEES-strength
input* rather than replacing it. Its proper role in the campaign is
Theorems A and D: an independent, exception-free reduction that is
stronger than EEES far from the diagonal and that certifies a third of
a million additional pairs from the existing sweep.

import math, bisect, random
from math import comb, log, lgamma

def primes_upto(n):
    s = bytearray(b'\x01') * (n + 1); s[0:2] = b'\x00\x00'
    for p in range(2, int(n**0.5) + 1):
        if s[p]: s[p*p::p] = b'\x00' * len(s[p*p::p])
    return [p for p, v in enumerate(s) if v]
PR = primes_upto(200000)
pi_ = lambda x: bisect.bisect_right(PR, x)
logC = lambda n, k: lgamma(n+1) - lgamma(min(k, n-k)+1) - lgamma(max(k, n-k)+1)

def logU_sharp(n, i):
    return sum(int(log(n)/log(p) + 1e-12) * log(p) for p in PR if p < i)
def Usharp(n, i):
    u = 1
    for p in PR:
        if p >= i: break
        u *= p ** int(log(n)/log(p) + 1e-12)
    return u
def vp(n, i, p):
    e, a, b, c = 0, n, i, n - i
    while a: a //= p; b //= p; c //= p; e += a - b - c
    return e
def logu_true(n, i):
    return sum(vp(n, i, p) * log(p) for p in PR if p < i)

# tightness table (section 4d): prints log u, log U#, log U, (1/2) log C
for (n, i) in [(100,10),(240,30),(1000,50),(1000,500),(10000,100),
               (10000,500),(10000,1000),(56,13),(16,3)]:
    print(n, i, round(logu_true(n, i), 2), round(logU_sharp(n, i), 2),
          round(pi_(i-1) * log(n), 2), round(0.5 * logC(n, i), 2))

# exact interval tops and sharp bad sets
def NK_exact(i, j):
    tgt, p = comb(j, j - i), pi_(i - 1)
    bad = lambda n: comb(n, i) <= n**p * tgt
    if not bad(2*j): return 2*j - 1
    lo, hi = 2*j, 4*j + 10
    while bad(hi): hi *= 2
    while hi - lo > 1:
        m = (lo + hi)//2
        lo, hi = (m, hi) if bad(m) else (lo, m)
    return lo
def sharp_bad_exact(i, j):
    tgt = comb(j, j - i)
    return [n for n in range(2*j, NK_exact(i, j) + 3)
            if comb(n, i) <= Usharp(n, i) * tgt]
def NEEES_exact(i, j):
    tgt = comb(2*j, 2*(j - i))
    if comb(2*j, i) >= tgt: return 2*j - 1
    lo, hi = 2*j, 4*j + 10
    while comb(hi, i) < tgt: hi *= 2
    while hi - lo > 1:
        m = (lo + hi)//2
        lo, hi = (m, hi) if comb(m, i) < tgt else (lo, m)
    return lo
for (i, j) in [(3,5),(3,6),(3,7),(3,9),(3,20),(4,7),(4,12),(5,8),
               (5,15),(10,16),(10,19),(10,30),(10,100)]:
    bad = sharp_bad_exact(i, j)
    print(i, j, "NK=", NK_exact(i, j), "N=", NEEES_exact(i, j),
          "sharp_bad=", bad if len(bad) <= 6 else
          f"max={max(bad)} count={len(bad)}")
# (3,7) prints NK=16, sharp_bad=[16]: the equality obstruction

# Theorem D count (float thresholds; exact recount agrees: 328079)
NSTAR, tot = 10000, 0
for i in range(1, 1001):
    tE = logC(NSTAR + 1, i); tK = tE - pi_(i - 1) * log(NSTAR + 1)
    def largest(ok):
        a, b = i, 5000
        while a < b:
            m = (a + b + 1)//2
            a, b = (m, b) if ok(m) else (a, m - 1)
        return a
    jE = largest(lambda j: logC(2*j, 2*(j - i)) <= tE)
    jK = largest(lambda j: logC(j, j - i) < tK)
    lo = 3*i//2 + 1
    if jK >= lo: tot += max(0, jK - max(jE, lo - 1))
print("new pairs:", tot)   # 328079
