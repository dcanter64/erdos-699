# Strategy S4 — Kummer Digit Classification of the Large Primes

**Problem #699.** For $1 \le i < j \le n/2$, show $\gcd(V_i(n), \binom{n}{j}) > 1$,
where $V_i(n)$ is the part of $\binom{n}{i}$ supported on primes $\ge i$.
**Established inputs used:** the finite reduction (a counterexample with
$(n,i)$ not one of the 12 EEES78 exception pairs satisfies
$\binom{n}{i} < \binom{2j}{2(j-i)}$; PHASE0), the closure of $j \le 3i/2$
(PHASE0, Item 3), EEES78 ($V_i(n) > \binom{n}{i}^{1/2}$ outside the 12
exception pairs $(8,3),(9,4),(10,5),(12,5),(21,7),(21,8),(30,7),
(33,13),(33,14),(36,13),(36,17),(56,13)$), and the sweep (no
counterexample with $n \le 10000$, $j > 3i/2$; RESULTS).

---

## 1. Idea paragraph

Kummer's theorem turns the divisibility question "$p \mid \binom{n}{k}$?"
into a question about the base-$p$ digits of $n$ and $k$, and for large
$p$ the base-$p$ expansion of $n$ has only **two digits**. In that regime
the answer depends on a single comparison — the residue of $k$ mod $p$
against the residue of $n$ mod $p$ — the exponent is at most $1$, and
whether a prime dividing $\binom{n}{i}$ can fail to divide $\binom{n}{j}$
is decided entirely by whether $i$ and $j$ lie in the same or in
different residue bands modulo $p$. Classifying this exactly (Lemmas
2–4) shows that a "locally bad" prime (one dividing $\binom{n}{i}$ but
not $\binom{n}{j}$) is possible only in an explicit *bad configuration*:
$i$ and $j$ in different bands, with residues straddling $r = n \bmod p$.
A separate elementary Legendre argument (Lemma 1) shows every prime
$p > j$ is automatically good, with no digit hypothesis at all. Hence a
counterexample forces **every** prime factor $\ge i$ of $\binom{n}{i}$
to lie in $[i, j]$ and, for those $> \sqrt n$, to sit in a bad
configuration with exponent exactly $1$. That rigid anatomy is what a
size argument can then attack: in the wedge $256i < n < i^2$,
$3i/2 < j < 2i$ it already yields a contradiction (Section 5), and in
general it reduces the problem to controlling the small primes
$p \le \sqrt n$ and the simultaneous congruences that bad
configurations impose on $n$.

## 2. Digit-classification lemmas

**Setup and notation.** Throughout, $p$ is prime, $1 \le k \le n/2$,
$t = \lfloor n/p \rfloor$, $r = n - tp$ (so $0 \le r < p$), and
$k = ap + s$ with $a = \lfloor k/p \rfloor$, $s = k \bmod p$
($0 \le s < p$). Kummer's theorem: $v_p\binom{n}{k}$ equals the number
of carries when adding $k$ and $n-k$ in base $p$ (equivalently the
number of borrows when subtracting $k$ from $n$).

### Lemma 0 (the two-digit regime is exactly $p > \sqrt n$)

$n$ has exactly two base-$p$ digits, $n = (t, r)_p$ with $t < p$, iff
$p \le n < p^2$, i.e. (for a prime that can divide a binomial
coefficient $\binom{n}{k}$, $k \ge 1$) iff $p^2 > n$. In this regime,
for every $k \le n/2$:

$$a = \lfloor k/p \rfloor \le \lfloor t/2 \rfloor.$$

*Proof.* $t < p \iff \lfloor n/p \rfloor \le p-1 \iff n \le p^2 - 1$.
For the bound on $a$: $ap \le k \le n/2 = (tp+r)/2 < p(t+1)/2$, so
$a < (t+1)/2$, i.e. $a \le \lfloor t/2 \rfloor$ since $a$ is an integer.
∎

### Lemma 1 (universal good range: every $p > j$ is good — no digit hypothesis)

Let $p$ be a prime with $p > j$. Then
$p \mid \binom{n}{i} \Rightarrow p \mid \binom{n}{j}$.

*Proof.* For any $k < p$, Legendre's formula gives
$v_p\binom{n}{k} = \sum_{a \ge 1} \big(\lfloor n/p^a \rfloor -
\lfloor k/p^a \rfloor - \lfloor (n-k)/p^a \rfloor\big)$, every summand
is $0$ or $1$ (hence $\ge 0$), and $\lfloor k/p^a \rfloor = 0$ since
$p^a \ge p > k$. Hence the $a$-th summand equals the number of
multiples of $p^a$ in the interval $(n-k, n]$, and therefore

$$v_p\tbinom{n}{k} \ge 1 \iff (n-k,\, n] \text{ contains a multiple of } p$$

(the forward direction: a summand equal to $1$ gives a multiple of
$p^a$, which is a multiple of $p$; the reverse direction: a multiple
of $p$ in the interval makes the $a = 1$ summand $\ge 1$). Apply this
with $k = i$ and $k = j$ (both $< p$ since $i < j < p$): if
$p \mid \binom{n}{i}$ then $(n-i, n]$ contains a multiple of $p$, and
$(n-i, n] \subseteq (n-j, n]$, so $p \mid \binom{n}{j}$. ∎

**Corollary 1.1.** In a counterexample, *every* prime divisor
$p \ge i$ of $\binom{n}{i}$ satisfies $p \le j$. This holds for **all**
$p$, including $p \le \sqrt n$; the digit classification below is
needed only inside the range $i \le p \le j$.

### Lemma 2 (master two-digit criterion)

Assume $p^2 > n$, with $t, r, a, s$ as above. Then for every
$k \le n/2$,

$$v_p\tbinom{n}{k} = \mathbf 1[\,s > r\,] \in \{0, 1\}.$$

In particular the exponent is capped at $1$, and
$p \mid \binom{n}{k} \iff (k \bmod p) > (n \bmod p)$.

*Proof (Kummer, digit by digit).* By Lemma 0, $n = (t, r)_p$,
$k = (a, s)_p$ with $a \le \lfloor t/2 \rfloor \le t$.

*Case $s \le r$.* Then $n - k = (t-a)p + (r-s)$ with
$0 \le r - s < p$ and $0 \le t - a < p$, so $n - k = (t-a,\, r-s)_p$.
Adding $k + (n-k)$ digitwise: low digit $s + (r - s) = r < p$ (no
carry), high digit $a + (t - a) = t < p$ (no carry). Zero carries,
$v_p = 0$.

*Case $s > r$.* Then $n - k = (t-a-1)p + (r - s + p)$, where
$0 < r - s + p < p$ and $t - a - 1 \ge 0$ (since $a \le \lfloor t/2
\rfloor$; for $t = 1$, $a = 0$ and $t - a - 1 = 0$). So
$n - k = (t-a-1,\, r-s+p)_p$. Adding: low digit
$s + (r - s + p) = r + p \in [p, 2p)$ (exactly one carry), high digit
$a + (t - a - 1) + 1 = t < p$ (no further carry). Exactly one carry,
$v_p = 1$. ∎

*Cross-check (Legendre).* Since $p^2 > n$, Legendre's sum has the
single term $a = 1$: $v_p = t - a - \lfloor (n-k)/p \rfloor$, and
$\lfloor (n-k)/p \rfloor = t - a$ if $s \le r$, $t - a - 1$ if
$s > r$. Same conclusion. ∎

### Lemma 3 ($t = 1$: primes in $(n/2, n]$ are all good)

Let $p \in (n/2, n]$, so $t = 1$, $n = (1, r)_p$, $r = n - p < n/2$.
For $k \le n/2 < p$: $a = 0$, $s = k$, and by Lemma 2
$p \mid \binom{n}{k} \iff k > r$. Hence
$p \mid \binom{n}{i} \Rightarrow i > r = n - p$, and since $j > i$,
also $j > r$, so $p \mid \binom{n}{j}$. No locally bad prime exists in
this range. (Note this is subsumed by Lemma 1, since $p > n/2 \ge j$;
the Kummer proof is the one requested for this range and it is the
template for $t \ge 2$.) ∎

### Lemma 4 ($t = 2$: primes in $(n/3, n/2]$)

Let $p \in (n/3, n/2]$ (for $n > 9$ this range implies $p^2 > n$,
since $p > n/3$ gives $p^2 > n^2/9 > n$; smaller $n$ are in the swept
region), so $t = 2$,
$n = (2, r)_p$, $r = n - 2p \in [0, p)$. By Lemma 0, $a \in \{0, 1\}$
for $k \le n/2$.

- **Sub-band $k < p$** ($a = 0$): $p \mid \binom{n}{k} \iff k > r$
  (Lemma 2).
- **Sub-band $k \ge p$** ($a = 1$): write $k = p + k'$. Since
  $k \le n/2 = p + r/2$, indeed $k' \le r/2$ (the bound in the brief
  is correct), so $s = k' \le r/2 \le r$ and Lemma 2 gives
  $v_p\binom{n}{k} = 0$. Directly in digits: $k = (1, k')_p$,
  $n - k = (1, r - k')_p$ (valid as $0 \le k' \le r$), digitwise sums
  $k' + (r - k') = r < p$ and $1 + 1 = 2 < p$: no carry. ∎

**Conclusion for $t = 2$.** $p \mid \binom{n}{i}$ and
$p \nmid \binom{n}{j}$ hold simultaneously iff

$$i \le r < p \le j \quad\text{more precisely}\quad r < i < p \le j \le p + \lfloor r/2 \rfloor,$$

i.e. exactly the configuration $i < p$, $i > r = n - 2p$, $j \ge p$
(and then automatically $j - p \le r/2 \le r$). In particular a locally
bad prime in this range forces $p \le j$ and $r < i$, equivalently
$\frac{n - i}{2} < p \le n - j$ (from $r < i$ and $j - p \le r$:
$n - 2p < i$ and $j - p \le n - 2p$).

*Verified example.* $(n, i, j, p) = (18, 5, 8, 7)$: $t = 2$, $r = 4$,
$r < i = 5 < 7 = p \le j = 8 \le 7 + 2$. Indeed
$v_7\binom{18}{5} = 1$, $v_7\binom{18}{8} = 0$. (The triple is not a
counterexample: other primes $\ge 5$, e.g. $17$, divide both.) ∎

### Lemma 5 (general $t$: the bad-configuration classification)

Assume $p^2 > n$ (equivalently $t < p$), $t \ge 1$ arbitrary. Write
$i = a_i p + s_i$, $j = a_j p + s_j$. Since $i < j$,
$a_i \le a_j \le \lfloor t/2 \rfloor$ (Lemma 0). By Lemma 2,
$p \mid \binom{n}{i} \iff s_i > r$ and
$p \nmid \binom{n}{j} \iff s_j \le r$. Hence:

$$p \text{ is locally bad} \iff a_i < a_j \ \text{and}\ s_i > r \ge s_j.$$

*Proof of the classification.* If $a_i = a_j$, then $i < j$ forces
$s_i < s_j$, so $s_i > r \Rightarrow s_j > r$: $p$ is good. If
$a_i < a_j$, the conditions $s_i > r \ge s_j$ are exactly Lemma 2's
two conditions, and they are also sufficient. ∎

**Consequences, valid for every $t \ge 1$ in the two-digit regime.**

1. **$p \le j$:** $a_i < a_j$ gives $a_j \ge 1$, so $j \ge p$.
   (Consistent with, and weaker than, Corollary 1.1.)
2. **A multiple of $p$ in $(i, j]$:** $a_i < a_j$ iff some multiple
   $(a_i + 1)p$ lies in $(i, j]$.
3. **$i < p$ is forced only for $t \le 3$.** For $t = 2$ and $t = 3$,
   $\lfloor t/2 \rfloor = 1$, so $(a_i, a_j) = (0, 1)$ is the only bad
   band pair, giving $i < p \le j$ as in Lemma 4. For $t \ge 4$,
   band pairs with $a_i \ge 1$ occur (Section 4).
4. **Linking inequalities:** $s_i > r$ and $s_j \le r$ rewrite as
   $$j + (t - a_j)p \;\le\; n \;<\; i + (t - a_i)p,
   \qquad\text{i.e.}\qquad
   \frac{n - i}{\,t - a_i\,} < p \le \frac{n - j}{\,t - a_j\,}$$
   (note $a_j \le \lfloor t/2 \rfloor < t$, so denominators are
   positive). Each bad prime thus pins $n \bmod p = r$ into the
   window $r \in [\,j - a_j p,\; i - a_i p\,) = [s_j, s_i)$, an
   interval of length $s_i - s_j = (a_j - a_i)p - (j - i) \in (0, p)$
   determined entirely by $i, j, p$.

**$t = 3$ explicitly** ($p \in (n/4, n/3]$, $n = (3, r)_p$,
$a \in \{0,1\}$): the analysis is identical in shape to $t = 2$. Bad
iff $r < i < p \le j$ with $j - p \le r$, equivalently
$\frac{n-i}{3} < p \le \frac{n-j}{2}$. Bad configurations **do exist**
— see Section 4.

## 3. The exact synthesis statement targeted

**Theorem S4-A (proved above).** *For all $1 \le i < j \le n/2$ and
every prime $p \ge i$: if $p \mid \binom{n}{i}$ and
$p \nmid \binom{n}{j}$, then $p \le j$; and if moreover $p^2 > n$,
then, with $t = \lfloor n/p \rfloor$, $r = n - tp$,
$a_i = \lfloor i/p \rfloor$, $a_j = \lfloor j/p \rfloor$:
$a_i < a_j$, $(i \bmod p) > r \ge (j \bmod p)$,
$v_p\binom{n}{i} = 1$, and $j + (t - a_j)p \le n < i + (t - a_i)p$.*

**Corollary (necessary anatomy of a counterexample).** *If
$(n, i, j)$ is a counterexample, then every prime divisor $p \ge i$ of
$\binom{n}{i}$ lies in $[i, j]$; every such prime with $p > \sqrt n$
has exponent exactly $1$ in $\binom{n}{i}$ and lies in a bad
configuration of Lemma 5. Writing $V_i(n) = V^{\le} \cdot V^{>}$ for
the parts on primes $\le \sqrt n$ and $> \sqrt n$: $V^{>}$ is
squarefree, composed only of bad-configuration primes in $[i, j]$,
and $V^{\le} = 1$ whenever $i > \sqrt n$.*

**Target Theorem S4-B (the synthesis to complete).** *For every
$(n, i)$ outside the 12 EEES78 exceptions, $V^{>}$ as above satisfies
$V^{>} \le \binom{n}{i}^{1/2} / V^{\le}$-compatible bounds strong
enough that, combined with EEES78 ($V_i(n)^2 > \binom{n}{i}$) and the
finite reduction, no counterexample exists in an explicit region
$\mathcal R$; ideally $\mathcal R$ = all $(i, j, n)$ with
$j > 3i/2$ in which $\binom{n}{i}$ is forced to have a prime factor
$> j$ or in which $i > \sqrt n$.* Section 5 proves S4-B in a first
explicit wedge of that region and states precisely what remains.

**On Sylvester–Schur-type inputs.** Classical Sylvester–Schur
($n > 2i \Rightarrow \binom{n}{i}$ has a prime factor $> i$) is
exactly the input already recorded on the problem page; it does
**not** give a prime factor $> j$, and no standard strengthening
gives $> 2i$ unconditionally in the needed range (the Erdős–Graham /
Shorey–Tijdeman results on the largest prime factor of
$\binom{n}{i}$ are asymptotic/ineffective for this purpose). So the
"$p > j$" route cannot be closed by quoting Sylvester–Schur alone:
Lemma 1 makes $p > j$ *sufficient*, but existence of such a prime
factor is a genuinely stronger anatomical claim about $\binom{n}{i}$,
false in general: all prime factors $\ge i$ of $\binom{n}{i}$ can
be $\le j$ (e.g. $(n, i, j) = (10, 3, 5)$: $\binom{10}{3} = 120$ has
prime factors $\ge 3$ exactly $3, 5$, both $\le j$ — the triple is
saved by the *good* small prime $3$, not by a prime $> j$). The
$p > j$ condition is sufficient, never necessary, so it cannot be
excluded a priori that a counterexample's prime factors all sit
$\le j$. The
usable substitute is the bad-configuration rigidity of Lemma 5 plus
size, as in Section 5.

## 4. Breaking point, honestly

**(a) $t = 3$ bad configurations exist.** Minimal example:
$(n, i, j, p) = (15, 1, 5, 5)$: $t = 3$, $r = 0$, $s_i = 1 > 0 \ge
s_j = 0$, bands $(0, 1)$. $v_5\binom{15}{1} = 1$,
$v_5\binom{15}{5} = 0$ (indeed $\binom{15}{5} = 3003$). Interior
example with $r > 0$: $(n, i, j, p) = (23, 5, 8, 7)$: $t = 3$,
$r = 2$, $r < i = 5 < 7 = p \le j = 8$, $j - p = 1 \le r$;
$v_7\binom{23}{5} = 1$ ($\binom{23}{5} = 33649 = 7 \cdot 4807$),
$v_7\binom{23}{8} = 0$. So the $t = 2$ phenomenon is not an accident
of small $t$: the classification does not close $t = 3$ locally.

**(b) Bad configurations proliferate with $t$.** The bad band pairs
are the pairs $0 \le a_i < a_j \le \lfloor t/2 \rfloor$: there are
$\binom{\lfloor t/2 \rfloor + 1}{2} \sim t^2/8$ of them. Already at
$t = 4$ a bad prime can exceed $i$ itself in band terms ($a_i \ge 1$,
so $i > p$ is possible): $(n, i, j, p) = (49, 19, 24, 11)$ has
$t = 4$, $r = 5$, $i = 1\cdot 11 + 8$ ($s_i = 8 > 5$),
$j = 2\cdot 11 + 2$ ($s_j = 2 \le 5$), and indeed
$v_{11}\binom{49}{19} = 1$, $v_{11}\binom{49}{24} = 0$. For each band
pair, the residue window $s_i \in (r, p)$, $s_j \in [0, r]$ is
nonempty whenever $1 \le r \le p - 2$ (and degenerate-nonempty at
$r = 0$ or $r = p-1$ on one side), so local digit analysis alone
excludes *no* band pair and *no* residue window. What saves the
argument in principle is that a counterexample needs **all** of its
large prime factors to be bad **simultaneously**, i.e. $n$ must
satisfy one congruence window modulo every bad prime at once — a
CRT/sieve condition, not a local one. This route does not, by itself,
bound how many such primes can conspire.

**(c) $p \le \sqrt n$: the classification collapses.** If
$p^2 \le n$, $n$ has $\ge 3$ base-$p$ digits. Lucas's theorem still
gives the *support* criterion ($p \nmid \binom{n}{k}$ iff every digit
of $k$ is $\le$ the corresponding digit of $n$), so
$p \mid \binom{n}{i}$, $p \nmid \binom{n}{j}$ is still a digitwise
statement — but now it can be witnessed at *any* digit position, the
positions for $i$ and $j$ need not be related, and the exponent cap
fails: e.g. $v_2\binom{12}{6} = 2$ ($924 = 4 \cdot 231$), two carries.
In general $v_p$ can be as large as the number of base-$p$ digits of
$n$. The part $V^{\le}$ of $V_i(n)$ on primes in $[i, \sqrt n]$ (this
range is nonempty only when $i \le \sqrt n$) is therefore
uncontrolled by Lemmas 2–5: no squarefreeness, no band structure, no
$p \le j$ beyond Corollary 1.1. **This is the main open flank of the
route.** Note it is vacuous when $i > \sqrt n$, which is exactly the
wedge Section 5 exploits.

**(d) The size bound is too weak outside the wedge.** Even with
$V^{>}$ squarefree on primes in $[i, j]$, the trivial bound
$V^{>} \le \prod_{p \le j} p \le 4^j$ is exponential in $j$, while in
the heart of the remaining region $n$ is only $O(j)$ (the finite
reduction leaves $n \in [2j, N(i,j)]$), so $\binom{n}{i}$ can be as
small as $\approx (2j)^i / i!$ and EEES78's
$V_i(n) > \binom{n}{i}^{1/2}$ is not contradicted. The wedge proof
below needs $n/i$ large (to beat $4^j$) **and** $j < 2i$ (to convert
$j$ into $i$) **and** $i > \sqrt n$ (to kill $V^{\le}$); removing any
one of the three breaks the inequality chain. Closing more requires
either a bound on the *number* of simultaneously bad primes (a sieve
input about the congruence windows of Lemma 5, Consequence 4), or
control of $V^{\le}$, or a largest-prime-factor result stronger than
what is currently available unconditionally.

## 5. What the synthesis closes: an explicit wedge

**Theorem S4-C (closed wedge).** *There is no counterexample with*

$$i > 256, \qquad 256\,i < n < i^2, \qquad 3i/2 < j < 2i$$

*((n, i) is automatically not an EEES78 exception, since those have
$n \le 56$; the region is nonempty, e.g. $i = 300$, $n = 80000$,
$j = 500$.)*

*Proof.* Suppose $(n, i, j)$ in this region were a counterexample.
Since $i > \sqrt n$ (as $n < i^2$), every prime divisor $p \ge i$ of
$\binom{n}{i}$ satisfies $p > \sqrt n$, so by the Corollary to S4-A,
$V_i(n) = V^{>}$ is a product of **distinct** primes in $[i, j]$, each
to the first power. Hence, using the elementary Chebyshev bound
$\prod_{p \le x} p \le 4^x$,

$$V_i(n) \;\le\; \prod_{i \le p \le j} p \;\le\; \prod_{p \le j} p \;\le\; 4^j,
\qquad V_i(n)^2 \le 16^j.$$

EEES78 gives $V_i(n)^2 > \binom{n}{i}$, and
$\binom{n}{i} \ge (n/i)^i$ (each factor $(n - s)/(i - s) \ge n/i$ for
$0 \le s < i$). With $n > 256 i$ and $j < 2i$:

$$\binom{n}{i} \;\ge\; (n/i)^i \;>\; 256^i = 16^{2i} \;>\; 16^j \;\ge\; V_i(n)^2 \;>\; \binom{n}{i},$$

a contradiction. ∎

*Remarks.* (i) The constant $256$ comes from the crude primorial
bound $4^j$; the explicit Rosser–Schoenfeld bound
$\theta(j) < 1.1\, j$ (to be referee-checked before use) would lower
the threshold to $n > 82\,i$, $i > 82$. (ii) The wedge is disjoint
from the swept region's purpose: it is an *infinite* family (all
$i > 256$) in the open region $j > 3i/2$, closed purely by digit
classification + EEES78 + an elementary size bound. (iii) It does not
touch $j \ge 2i$, $n \le 256 i$, or $i \le \sqrt n$ — see Section 4(d).

## 6. Bounded computation (Python stdlib, < 1 minute)

The script below (run as executed; total wall time $\approx 38$ s)
verifies the classification in three parts:

- **Part A ($n \le 500$, the classification itself).** For every
  $n \le 500$, every prime $p$ with $p^2 > n$, and every
  $k \le n/2$: Legendre $v_p\binom{n}{k}$ (single term, since
  $p^2 > n$) is compared against the Lemma 2 prediction
  $\mathbf 1[(k \bmod p) > (n \bmod p)]$. Since Lemma 5's bad
  configuration is exactly the conjunction of Lemma 2's predictions
  at $k = i$ and $k = j$, Part A logically implies the triple-level
  classification for **all** triples with $n \le 500$.
  **Result: 3,754,028 checks, 0 failures, maximum exponent observed
  $= 1$** (confirming the exponent cap).
- **Part B (direct triple scan, $n \le 250$).** For every triple and
  every prime $p \ge i$ with $p \mid \binom{n}{i}$,
  $p \nmid \binom{n}{j}$ (independent general Legendre computation):
  **1,268,638 locally bad incidences, of which 1,230,242 have
  $p^2 > n$ and every single one lies in the Lemma 5 bad
  configuration (0 violations); 0 incidences have $p > j$**
  (empirically confirming Lemma 1 / Corollary 1.1 across all digit
  sizes; the remaining 38,396 incidences are the multi-digit regime
  $p^2 \le n$, outside Lemma 5's scope). The worked examples of
  Lemmas 4–5 and Section 4 ($(18,5,8,7)$, $(23,5,8,7)$,
  $(49,19,24,11)$) are re-verified in the script's tail.
- **Part C ($n \le 200$).** Direct $\gcd$ anatomy: **328,350 triples,
  0 with no common prime $\ge i$** (consistent with the established
  sweep; included only as a sanity check on the local analysis).

```python
import time
from collections import Counter
t0 = time.time()

def primes_upto(N):
    sieve = bytearray(b'\x01') * (N + 1); sieve[0:2] = b'\x00\x00'
    for i in range(2, int(N**0.5) + 1):
        if sieve[i]: sieve[i*i:N+1:i] = bytearray(len(sieve[i*i:N+1:i]))
    return [i for i in range(N + 1) if sieve[i]]

def vp(n, k, p):                      # Legendre, general
    e = 0; pp = p
    while pp <= n:
        e += n//pp - k//pp - (n-k)//pp
        if pp > n//p: break
        pp *= p
    return e

N = 500; primes = primes_upto(N)
# Part A: single-k criterion, two-digit primes, n <= 500
cnt = 0; fails = []; maxv = 0
for n in range(2, N + 1):
    for p in primes:
        if p > n: break
        if p * (p + 1) <= n: continue
        t = n // p; r = n - t * p
        if t >= p: continue           # exactly the regime p^2 > n
        for k in range(1, n//2 + 1):
            v = vp(n, k, p); cnt += 1; maxv = max(maxv, v)
            if (v >= 1) != ((k % p) > r): fails.append((n, k, p, v))
print("Part A:", cnt, "checks, fails =", len(fails), ", max vp =", maxv)

# Part B: triple scan, n <= 250
N2 = 250; total_bad = 0; viol = 0; pgtj = 0; ctr = Counter()
for n in range(2, N2 + 1):
    divs = {k: [p for p in primes if p <= n and vp(n, k, p) >= 1]
            for k in range(1, n//2 + 1)}
    for i in range(1, n//2 + 1):
        for p in divs[i]:
            if p < i: continue
            t = n // p; r = n - t * p; two = (t < p)
            for j in range(i + 1, n//2 + 1):
                if vp(n, j, p) == 0:
                    total_bad += 1
                    if p > j: pgtj += 1
                    if two:
                        if not (i//p < j//p and i % p > r >= j % p): viol += 1
                        ctr[t] += 1
                    else: ctr['multi'] += 1
print("Part B: locally bad =", total_bad, ", two-digit violations =",
      viol, ", p>j incidences =", pgtj, ", by t/multi =", dict(ctr))
for (n, i, j, p) in [(18, 5, 8, 7), (23, 5, 8, 7), (49, 19, 24, 11)]:
    print((n, i, j, p), "vp_i =", vp(n, i, p), "vp_j =", vp(n, j, p),
          "t, r =", n//p, n % p)

# Part C: no-counterexample sanity scan, n <= 200
noc = 0; cnttr = 0
for n in range(2, 201):
    D = {k: set(p for p in primes if p <= n and vp(n, k, p) >= 1)
         for k in range(1, n//2 + 1)}
    for i in range(1, n//2 + 1):
        for j in range(i + 1, n//2 + 1):
            cnttr += 1
            if not any(p >= i for p in (D[i] & D[j])): noc += 1
print("Part C:", cnttr, "triples, no-common-prime =", noc,
      ", total time", round(time.time() - t0, 1), "s")
```

## 7. Summary of status

- **Proved:** Lemma 1 ($p > j$ universally good); Lemma 2 (two-digit
  criterion, exponent $\le 1$); Lemmas 3–4 ($t = 1$ fully good;
  $t = 2$ bad iff $r < i < p \le j$); Lemma 5 (general-$t$ bad
  classification, $p \le j$, band/residue/linking-inequality form);
  Theorem S4-C (explicit infinite wedge closed).
- **Targeted, not proved:** Theorem S4-B in general — needs control
  of $V^{\le}$ ($p \le \sqrt n$, multi-digit, exponents $> 1$) and/or
  a bound on simultaneously bad large primes.
- **Breaking point:** $p \le \sqrt n$ (Section 4(c)) and the weakness
  of the product bound $4^j$ when $n = O(j)$ or $j \ge 2i$
  (Section 4(d)). Bad configurations exist at every $t \ge 2$,
  including $t = 3$ ($(15,1,5,5)$, $(23,5,8,7)$) and with $i > p$ at
  $t = 4$ ($(49,19,24,11)$).
